# Talking Travel – вёрстка макета

Учебный проект: две страницы макета, HTML и CSS без программной логики.

- **Макет:** [Figma](https://www.figma.com/design/xc3vHAMZNq9Nm9x2TgnHei/Locofy-Sample-Project---Talking-Travel--Community-)
- **Опубликованная версия:** https://fallingstash.github.io/web_lab1/

## Структура проекта
- `index.html` — главная страница
- `blog.html` — страница блога (список записей)
- `css/style.css` — файл стилей
- `docs/decomposition.md` — декомпозиция и оценка работ

## Принятые решения
Места, где макет не задавал правила, или которые были упрощены для экономии времени:
1. **Изображения:** Вместо экспорта картинок из Figma использованы тематические фотографии с сервиса Unsplash. Это ускорило работу и обеспечило оптимизированный размер файлов.
2. **Адаптив шапки:** На узком экране (360px) меню навигации переносится на новую строку с помощью `flex-wrap: wrap`, что является допустимым и читаемым решением без использования JavaScript.
3. **Состояния элементов:** Для интерактивных элементов (кнопки, ссылки) добавлены состояния `:hover` (изменение цвета). 

## Проверка
- **Валидатор W3C:** Разметка `index.html` и `blog.html` успешно прошла проверку. Ошибок не обнаружено (0 errors).
- **Доступность (Accessibility):** Реализован видимый фокус для элементов при навигации с клавиатуры (`:focus-visible`). Добавлены атрибуты `aria-label` для кнопок-иконок.
- **Адаптивность:** Проверены контрольные ширины 360, 768 и 1280 пикселей. Горизонтальная прокрутка на мобильных устройствах отсутствует. 
- **Изображения:** Все теги `img` имеют атрибут `alt` (альтернативный текст).
